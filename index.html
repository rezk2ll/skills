Claude Code skills and guardrails I use every day

Skills for pull requests, reviews, releases and design docs. Hooks that stop an agent before it merges, leaks a secret or ships an untested change. All installable as Claude Code plugins.

Browse the catalog How I work
Install any item in one line
/plugin install pr --marketplace rezk2ll/skills
Or add the marketplace and browse everything in /plugin
/plugin marketplace add rezk2ll/skills

Run these inside Claude Code 2.1.275 or later. Skills also work without plugins: copy a folder from the repository into ~/.claude/skills.
