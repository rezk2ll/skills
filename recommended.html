Recommended

What else I keep installed in Claude Code. None of it is mine: install it from the authors.

MCP servers

Servers that give Claude live access to the tools you already use. Add only the ones you need: each one costs context on every turn.

GitHub

GitHub's official MCP server: issues, pull requests, reviews, Actions runs.

Reading PR threads and CI logs without leaving the session. Pair it with the guard hook so nothing gets posted as you by accident.

/plugin install github@claude-plugins-official
Playwright

Drives a real browser: navigate, click, fill forms, take screenshots, read the console.

The fastest way to let Claude check its own UI work at desktop and phone widths.

$ claude mcp add playwright npx @playwright/mcp@latest
Context7

Current, version-specific documentation for libraries and frameworks.

Stops Claude from writing code against an API that changed two majors ago.

$ claude mcp add --transport http context7 https://mcp.context7.com/mcp
Sentry

Issues, events and stack traces from your Sentry projects.

Debugging from the real production stack trace instead of a guess.

$ claude mcp add --transport http sentry https://mcp.sentry.dev/mcp
Figma

Reads frames, components and variables from Figma files.

Building a screen from the actual design tokens, not from a screenshot.

$ claude mcp add --transport http figma https://mcp.figma.com/mcp

Plugins

Plugins I keep installed. Most come from the official Anthropic directory.

code-review

Reviews the current diff for bugs and fixes what it finds.

First step of my review chain before any pull request.

/plugin install code-review@claude-plugins-official
ponytail

Hunts over-engineering: code you did not need to write.

Second step of the review chain. I use it as a reviewer after the code exists, not as a persona while writing.

superpowers

A skills framework with brainstorming, planning and execution workflows.

Good structure for larger features that need a plan before code.

typescript-lsp and gopls-lsp

Language servers, so Claude gets real diagnostics and go-to-definition.

Catches type errors right after an edit instead of at the end of the task.

/plugin install typescript-lsp@claude-plugins-official/plugin install gopls-lsp@claude-plugins-official
frontend-design

Design guidance for building interfaces that do not look generated.

Better first drafts for UI work.

/plugin install frontend-design@claude-plugins-official
skill-creator

Helps you write, test and improve your own skills.

Most of the skills on this site started there.

/plugin install skill-creator@claude-plugins-official
agent-notifications

Desktop notifications when Claude finishes or needs input.

Lets me run several sessions and only look when one needs me.

Skills by other people

Skills I use every week but did not write. Install them from their authors.

mattpocock/skills

grill-me, tdd, diagnosing-bugs, codebase-design, handoff, research, writing-for-agents and more.

grill-me before any big change, tdd for bug fixes, handoff when a session gets long. The best general set out there.

humanizer

Removes the signs of AI writing from text.

I run it on every PR description, issue and doc before it goes out.

agent-skills

Engineering skills for AI coding agents by Addy Osmani.

Solid defaults for performance, accessibility and web quality work.

Mods by other people

Mods are plugins with JavaScript handlers that run inside Claude Code (version 2.1.287 or later). They run with your permissions, so read the code first.

cctop

A btop-style live dashboard for context, tokens, cost, limits, tools and agents, in a pane next to your session.

The quickest answer to "why is this session slow and expensive".

claude-code-mods

A collection of panes, bands, prompt guards, secret handling and memory tools.

A good tour of what mods can do. My secret-redactor started from an idea here.

aside

A read-only side chat, so you can ask a question without derailing the main task.

Questions mid-task stop polluting the main context.

cc-pr-tracker

Shows merge state, reviews and required checks of your PRs above the prompt.

No more switching to the browser to see whether CI passed.

claude-mods (usage band)

Always-visible 5-hour and weekly usage limits with a reset countdown.

You see the limit coming instead of hitting it.

pixelband and Claude Fables

Animated pixel art and little cartoons above the prompt while Claude works.

Useless and charming. Zero tokens.

Command line tools

Not Claude Code plugins, but they change how a session feels.

rtk

A command proxy that condenses the output of common dev commands before Claude reads it.

Long test and build logs stop eating the context window.

GitHub CLI

gh: pull requests, issues, Actions and the GitHub API from the shell.

Most skills here use it. Claude is very good with it.
